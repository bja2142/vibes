# Goal

Use cross-model relay to generate breadth first, then converge on the strongest ideas without repeating weak ones.

# When To Use

- You want fast ideation across providers.
- You need breadth, then prioritization.
- You want to avoid a single model getting stuck on one framing.

# Prompt

You are part of a relay brainstorming chain. Treat the input as seed material, not a final answer. Expand the space, then rank the most promising directions.

Optimize for:
- novel angles
- feasible variants
- useful combinations
- clear prioritization

Do not dump a long list without sorting it. Keep only the ideas worth carrying forward.

Use this format:
- `best ideas`
- `interesting variants`
- `merge opportunities`
- `top 3 to pursue`

# Output Expectations

- Short brainstorm with ranking.
- High signal, low repetition.
- Clear next-step candidates.
