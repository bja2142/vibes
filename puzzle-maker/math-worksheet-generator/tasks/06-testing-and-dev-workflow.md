# Task 06: Testing And Development Workflow

## Goal

Add the test harness and development environment needed to keep generation reproducible.

## Scope

- Unit-test generators, mapping, validation, and approval flow
- Add snapshot coverage for rendering where practical
- Add end-to-end tests for full worksheet generation
- Add Docker-based development and test commands

## Deliverables

- Automated test suite
- Dockerfile and reproducible developer commands
- Test fixtures and mocks for external generation

## Acceptance Criteria

- Core generation logic is covered by automated tests
- External reward-content generation is mockable
- A new developer can build and test the project through Docker
