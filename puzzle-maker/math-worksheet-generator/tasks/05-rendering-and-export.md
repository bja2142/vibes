# Task 05: Rendering And Export

## Goal

Turn validated worksheet data into printable layouts and preview assets.

## Scope

- Render prompt, instructions, problem list, lookup area, and answer area
- Support both letter-bank and color-by-number reveal modes
- Keep layouts printer-friendly and readable across learner bands
- Export PDF first, with SVG and PNG as secondary outputs

## Deliverables

- Renderer module
- Export module
- Layout fixtures for representative learner bands

## Acceptance Criteria

- Valid worksheets render without clipping or overlap
- Both reveal modes are visually usable
- Exported artifacts are legible and printable
